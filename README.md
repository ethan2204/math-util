# Math Utility

A small Java/Maven library built for the **Software Testing** course at FPT University to practise unit testing and continuous integration.

## What's inside

- A Maven project implementing a Math Util library
- JUnit tests demonstrating **unit testing**, **Test-Driven Development (TDD)** and **Data-Driven Testing (DDT)**
- A **GitHub Actions** CI pipeline that builds the project and runs the tests on every push and pull request to `main`
